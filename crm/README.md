# UMED CRM

Один сайт с личными кабинетами для команды UMED: расписание и свободные кабинеты, наборы, группы и ученики,
посещаемость и быстрые тесты, ДЗ, касания с родителями, переводы и уходы, риски, отзывы, опросник,
красная зона и отчёты по сотрудникам. Требования — в [`../docs/TZ-UMED-CRM.md`](../docs/TZ-UMED-CRM.md).

Стек: Next.js 15 + Prisma + PostgreSQL. Уведомления только внутри сайта, внешних интеграций нет.

## Как опубликовать (≈15 минут, без терминала)

1. **Supabase** (supabase.com) → New project. Регион: **Central EU (Frankfurt)**. Придумайте и сохраните пароль базы.
   Когда проект создастся: кнопка **Connect** вверху → вкладка **ORMs** → **Prisma**. Там две строки:
   `DATABASE_URL` и `DIRECT_URL`. Замените в них `[YOUR-PASSWORD]` на свой пароль.
2. **Vercel** (vercel.com) → Add New → Project → Import репозитория `my-gemini-bot`.
   - **Root Directory:** `crm`
   - **Environment Variables:**
     - `DATABASE_URL` — строка из Supabase
     - `DIRECT_URL` — строка из Supabase
     - `SESSION_SECRET` — любая длинная случайная строка (например, 40 любых букв и цифр)
   - **Deploy.** Таблицы в базе создаются автоматически при каждой публикации.
3. **Откройте ссылку сайта** → появится «Первый запуск» → введите имя, логин и код. Филиалы и кабинеты создадутся сами.
4. «Сотрудники» → добавьте руководителей отделов (галочка «Руководитель отдела»). Дальше они добавляют своих сотрудников.

Сайт работает в регионе Франкфурт (`vercel.json`) — рядом с базой, поэтому быстро.
Vercel публикует ветку `main`: изменения попадают на сайт после слияния pull request.

## Как это работает

- **Права**: полный доступ → руководители отделов → сотрудники. Руководитель отдела создаёт сотрудников только
  своего отдела и включает им разделы (например, руководитель менеджеров — доступ к финансам).
- **Задачи и красная зона** создаются автоматически при открытии сайта (не чаще раза в 30 секунд):
  назначить преподавателей и куратора после закрытия набора, 3 дня до старта, посещаемость до конца занятия,
  ДЗ до следующего занятия, «принять ДЗ» в ожидаемую дату, касания после 6-го и 12-го занятия,
  опросник на последней неделе месяца.
- **Авто-риски**: 2 пропуска подряд без причины; 3 несданных ДЗ подряд; негативный отзыв с риском ухода.
- **Уход / перевод** — красное уведомление всем, «Принято» в течение 24 часов, иначе руководство видит, кто не принял.
- **Удержание**: база — ученики на старте курса; пришедшие позже считаются со следующего месяца.
  Отметку «отток / не отток» отдельно для куратора, преподавателей и бизнеса ставит полный доступ («Движения»).
- Время — Бишкек (UTC+6). Месяц курса = 12 занятий.

## Разработка

```bash
npm install && npx prisma db push
npm run dev        # http://localhost:3000 → откроется «Первый запуск»
npm run typecheck
```
