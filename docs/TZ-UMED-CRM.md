# UMED CRM — техническое задание (v1)

Дата: 08.11.2026 · Автор требований: Жанетта (руководитель кураторов)

Один сайт, личный кабинет у каждого сотрудника, уведомления только внутри сайта. Без интеграций (Telegram, WhatsApp, API — не делаем).

---

## 1. Организационная структура

| Филиал | Кабинеты | Вместимость |
|---|---|---|
| Медерова | Кабинет 1, 2, 3, 4 | до 22 учеников в группе |
| Байтик Баатыра | Кабинет 1, 2, 3, 4 | до 22 учеников в группе |
| Онлайн | — | без лимита |

- Курс: офлайн — 5 месяцев, онлайн — 4 месяца.
- Дни: Пн-Ср-Пт или Вт-Чт-Сб. Слоты: 15:00–17:00, 17:00–19:00, 19:00–21:00 (онлайн — те же).
- Месяц курса = 12 занятий: неделя 1 и 3 — химия (3 занятия), неделя 2 и 4 — биология (3 занятия).
- У группы 1 преподаватель химии + 1 преподаватель биологии на весь курс, 1 куратор. Замену преподавателя делает админ.
- Оплата: 9 000 сом в месяц, одинаково для всех (сумму можно изменить в настройках).

## 2. Роли и права доступа

### 2.1. Уровни
1. **Полный доступ** — Жанетта + те, кому она выдаст (основной руководитель). Видят и редактируют всё, выдают любые права.
2. **Руководители отделов** — руководитель админов, кураторов, менеджеров, преподавателей. Сами создают сотрудников своего отдела (логин + код) и включают/выключают им разделы. Пример: руководитель менеджеров решает, у кого из менеджеров есть доступ к финтаблице.
3. **Сотрудники** — работают в рамках выданных разделов.

Вход: логин + код. Код выдаёт руководитель, может сбросить.

## 3. Основные сущности
- **Сотрудник**: ФИО, роль, отдел, руководитель, логин, код, выданные разделы.
- **Группа**: филиал, кабинет, дни, слот, дата старта, название (по умолчанию «Старт 10.11 · Вт-Чт-Сб · 15–17»; можно переименовать) + описание расписания, преподаватель химии, преподаватель биологии, куратор, статус (набор / ждёт старта / идёт / завершена).
- **Ученик**: ФИО, телефон, имя родителя, телефон родителя, группа, статус, биография (свободный текст куратора, необязательно), флаг «родители не участвуют» + причина (нет номера / сам оплачивает / другое).
- **Занятие**: группа, дата, номер (1–12) и месяц курса, предмет, преподаватель.
- **Посещаемость**: ученик × занятие: был / не был / отпросился заранее; причина; результат быстрого теста (офлайн); примечание (онлайн — итог обзвона).
- **ДЗ**: ученик × занятие × тип (опыт: сдано/не сдано; тест: балл X из Y); если не сдано — причина + ожидаемая дата сдачи.
- **Касание** (куратор отправляет родителю отчёт по ученику): ученик × месяц × номер (после 6-го и 12-го занятия): дата, «касание выполнено», ответ родителя — дословно или «ожидается ответ».
- **Отзыв**: дата, группа, ученик (или «анонимно»), от кого (родитель / ученик / сотрудник — какой), канал (личное сообщение / звонок / лично / чат), о чём (преподаватель химии / преподаватель биологии / куратор / админ / менеджер / организация / другое), тон (позитив / нейтрально / негатив), дословно или реакция, ссылка/скрин, риск ухода (да/нет — **обязательно при негативе**), что сделано, статус (открыт / в работе / решено / не решаемо), решение руководителя, срок проверки.
- **Движение ученика**: тип (перевод / уход / изменение состава / другое), из группы, в группу, причина из списка, дословно со слов ученика, что сделал куратор, фото, атрибуция (куратор / преподаватель химии / преподаватель биологии / бизнес), кто зафиксировал, подтверждения.
- **Риск**: ученик, источник (вручную куратором / автоматически), причина, статус (открыт / снят).
- **Оплата**: ученик × месяц: сумма, оплачено / не оплачено, причина неоплаты, ожидаемая дата.
- **Опросник**: группа × месяц: % преподаватель химии, % преподаватель биологии, % куратор, % админ.
- **Задача** и **уведомление**: кому, что, срок, статус, кнопка «Принято».
- **Журнал изменений**: кто, что, когда поменял.

Причины ухода (список, как в «Базе учеников UMED»): финансы / дорого, неудобное время / расписание, не понравился преподаватель / урок, переезд, нагрузка в школе, другое. Поля «дословно со слов ученика» и «что сделал куратор» обязательны.

| # | Событие | Кому задача / уведомление | Срок | Если не сделано |

## 5. Метрики

Все метрики считаются отдельно за неделю, месяц и весь курс, по группе, по филиалу и по сотруднику.

**Правила удержания:**
- База = число учеников **на старте курса**.
- Ученик, пришедший в месяце N (новый или переводом), входит в базу **со следующего месяца** (N+1).
- Удержание на конец каждого месяца курса (1–5 мес.) = 1 − ушедшие с отметкой «отток» / база.
- Три отдельных показателя: **для куратора**, **для преподавателя** (химия и биология отдельно) и **для бизнеса** — по отметке «отток / не отток», которую ставит полный доступ.
- Перевод внутри UMED для бизнеса — не отток. Для куратора или преподавателя — по отметке (пример из базы: перевод из-за преподавателя химии = отток для преподавателя, не отток для куратора).
- Уход без проверенной отметки считается оттоком, пока его не проверят (как в твоей таблице).

**Преподаватель** (отдельно химия и биология):
- Посещаемость = присутствовали / ученики в группе на занятиях этого преподавателя.
- Эффективность = средний % быстрых тестов (только офлайн).
- Удержание «для преподавателя» (см. правила выше).
- Опросник — % из опросника.

**Куратор**:
- Выполнение ДЗ = сданные / все ДЗ (опыты + тесты отдельно и вместе). 3 из 3 = 100%, 2 из 3 = 67%.
- Удержание «для куратора» (см. правила выше).
- Касания = выполненные / требуемые (цель 100%; исключены ученики с «родители не участвуют»).
- Опросник — % из опросника.

**Бизнес** (полный доступ): ученики всего, пришли, ушли (по причинам), удержание бизнеса, заполняемость кабинетов и слотов, занятия проведены, оплаты: ожидается / получено / долг.

**Отзывы:** всего / позитив / нейтрально / негатив, % негатива (красное, если > 15%), риски ухода и открытые — по группам, темам и сотрудникам. Раздел «Контроль»: негатив и риск ухода со статусом не «решено» / «не решаемо», дней открыто, просроченный срок проверки — красным.

У каждого руководителя отдела — график эффективности по сотрудникам своего отдела.

## 6. Экраны
1. Вход (логин + код).
2. Главная: мои задачи, красная зона, уведомления с «Принято».
3. Шахматка: филиал × кабинет × слот × дни, цвет по статусу, клик → открыть набор.
4. Группа: состав, посещаемость, ДЗ, касания, движения учеников, риски, описание.
5. Карточка ученика: прогресс (сколько занятий пройдено и осталось, % ДЗ, динамика), биография, касания, оплаты, история.
6. Сотрудники: управление доступами (для руководителей).
7. Дашборды: преподаватель, куратор, руководитель отдела, бизнес.
8. Финансы: оплаты учеников по месяцам, должники, ожидаемые оплаты.
9. Отзывы: кнопка «Отзыв» на каждом экране, список, сводка, контроль.

## 7. Этапы

- **Сейчас (MVP):** вход и права, шахматка и расписание, наборы, группы и ученики, посещаемость + быстрые тесты, ДЗ, движения учеников + «Принято», риски, отзывы, красная зона.
- **Следующим этапом:** касания, оплаты и задачи по неоплате, опросник, карточка прогресса, дашборды и удержание с атрибуцией.
- **Позже:** перенос активных групп и «Базы учеников UMED» (уходы, переводы, приходы, отзывы) из Google-таблиц, зарплаты (только полный доступ).
- **Не делать:** интеграции с мессенджерами, кабинет для учеников и родителей, воронку лидов, тип ученика, еженедельные регламентные задачи куратора из таблиц.

## 8. Решённые вопросы (08.11.2026)
- Удержание — от числа учеников на старте курса; новые входят в базу со следующего месяца.
- Отпросился — отмечает тот, у кого отпросились (куратор или админ), заранее.
- Риск по ДЗ — 3 несданных подряд.
- Месяц = 12 занятий группы (28 дней), не календарный.
- Кабинеты — «Кабинет 1–4».
- Касание — без эскалации: «выполнено» + ответ дословно или «ожидается ответ».

## 9. Открытые вопросы (есть вариант по умолчанию)
1. «Отпросился» считать пропуском в посещаемости преподавателя? По умолчанию — да, это пропуск, но автоматический риск не ставится.
2. Уход без отметки «отток / не отток» до проверки считать оттоком? По умолчанию — да, как в «Базе учеников UMED».
