# UMED CRM на Google Apps Script

Бесплатная версия: сайт работает на Google Apps Script, данные хранятся в Google-таблице.
Ничего, кроме Google-аккаунта, не нужно. Требования — в [`../docs/TZ-UMED-CRM.md`](../docs/TZ-UMED-CRM.md).

## Установка (≈15 минут, один раз)

Делайте всё под тем Google-аккаунтом, который будет **владельцем системы**
(лучше рабочий аккаунт UMED, а не личный — тогда система останется у компании).

1. **Создайте таблицу.** Google Таблицы → Пустая таблица → назовите «UMED CRM — база».
   Не давайте к ней доступ сотрудникам: они работают через сайт.
2. **Откройте редактор скрипта.** В таблице: *Расширения → Apps Script*.
3. **Вставьте код.**
   - В левой панели откройте файл `Код.gs` (или `Code.gs`), удалите всё и вставьте содержимое
     [`dist/Code.gs`](dist/Code.gs) (на GitHub — кнопка «Copy raw file»).
   - Нажмите **＋ → HTML**, назовите файл **`Index`** (без `.html`), удалите всё и вставьте [`dist/Index.html`](dist/Index.html).
   - Нажмите 💾 (Сохранить).
4. **Настройте систему.** Вернитесь во вкладку с таблицей и обновите страницу (F5).
   Появится меню **UMED CRM → Настроить систему**.
   - Google попросит разрешение: *Продолжить → выбрать аккаунт → «Дополнительные настройки» → «Перейти на страницу…» → Разрешить*.
     Предупреждение «приложение не проверено» — нормально для собственного скрипта.
   - Введите своё имя, логин (латиницей) и код. Создадутся листы, филиалы, по 4 кабинета и включится
     автопроверка задач каждые 10 минут.
5. **Опубликуйте сайт.** В редакторе скрипта синяя кнопка справа вверху *Развертывание (Deploy) → Новое развертывание (New deployment)*
   → ⚙ рядом с «Тип» → *Веб-приложение (Web app)* → «Запуск от имени (Execute as)»: **Я (Me)**,
   «У кого есть доступ (Who has access)»: **Все (Anyone)** → *Развернуть (Deploy)*.
   Скопируйте ссылку *Веб-приложение (Web app URL)* — это адрес сайта для команды.
6. **Войдите** по своему логину и коду → «Сотрудники» → добавьте руководителей отделов
   (галочка «Руководитель отдела»). Дальше они сами добавляют своих сотрудников и выдают им коды.

### Как обновить код
Вставьте новые `Code.gs` и `Index` → Сохранить → *Развертывание → Управление развертываниями (Manage deployments)*
→ ✏️ → Версия: **Новая версия (New version)** → *Развернуть*. Ссылка останется прежней.

## Что важно знать
- **Данные** — в листах таблицы (Группы, Ученики, Посещаемость, ДЗ, Касания, Движения, Риски, Отзывы, Задачи…).
  Их можно смотреть, но **не редактируйте и не переставляйте столбцы руками** — меняйте данные через сайт.
  Первая колонка ID связывает записи между собой.
- **Время** — Бишкек (UTC+6). Месяц курса = 12 занятий.
- **Автопроверка** каждые 10 минут создаёт задачи и красную зону (посещаемость до конца занятия, ДЗ до следующего
  занятия, касания, опросник, назначения после закрытия набора, авто-риски). Запустить вручную: меню
  *UMED CRM → Проверить задачи сейчас*.
- **Ограничения Google** (обычный аккаунт): около 90 минут работы автопроверки в сутки — системе хватает с запасом;
  одно сохранение занимает 1–3 секунды. Если два человека сохраняют одновременно, запросы выполняются по очереди.
- **Безопасность.** Сайт открыт по ссылке, но без логина и кода данные не видны. Коды хранятся зашифрованными.

## Для разработки
Исходники — в `src/` (по файлу на модуль). После правок:
```bash
node test/scenario.test.js           # 60+ проверок серверной логики на имитации Google
AS_DIST=1 node test/scenario.test.js # то же для собранного dist/Code.gs
node build.js                        # собрать dist/Code.gs и dist/Index.html
node test/serve.js 3200              # интерфейс локально: http://localhost:3200 (вход zhanetta / 1234)
```
